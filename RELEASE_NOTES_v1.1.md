# Édition v1.1 — 24 novembre 2026

Cette édition rassemble la présentation courte en français, l’édition courte
en anglais, le résumé exécutif anglais, le dossier technique complet et le
relevé public d’endurance accompagné de ses mesures filtrées et graphiques.

Le dossier a été actualisé pour mieux décrire la portée du moteur causal
multi-domaines, ses contrats temporels, ses campagnes intégrées, ses résultats
observés et ses limites. Les documents Markdown, HTML et PDF sont fournis pour
les éditions concernées. Les fichiers de l’édition v1.0 sont conservés dans
`archive/v1.0/` pour garder une trace des versions précédentes.

Cette version ne contient ni moteur ni code source, recette d’implémentation,
configuration privée, donnée brute ou procédure d’exécution interne. Tous
droits réservés.

Les photographies et captures d’écran ont été retirées des éditions publiques.
Cette édition conserve les graphiques et schémas explicatifs du projet.
