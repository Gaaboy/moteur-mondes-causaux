# Dépôt Zenodo — édition française corrigée

Le dossier français est publié sur GitHub :
[Gaaboy/moteur-mondes-causaux](https://github.com/Gaaboy/moteur-mondes-causaux).
L’édition anglaise est publiée séparément dans
[son dépôt dédié](https://github.com/Gaaboy/causal-worlds-engine-public).
Le moteur, son code source et ses recettes restent privés.

## Finaliser une nouvelle version Zenodo

1. Créer une nouvelle version du dépôt existant pour conserver l’historique.
2. Définir la langue sur français, conserver le titre français et vérifier le
   créateur **Gaaboy**, le résumé, les mots-clés et les droits réservés.
3. Téléverser uniquement l’archive française. Vérifier l’aperçu du ZIP :
   aucun fichier de l’édition anglaise ne doit y figurer.
4. Vérifier les métadonnées et l’aperçu public avant de publier.
5. Après publication, le DOI conceptuel renvoie vers la version la plus récente;
   citer ce DOI stable dans `CITATION.cff`.

Les métadonnées préparées se trouvent dans `.zenodo.json` et la référence
bibliographique dans `CITATION.cff`.
