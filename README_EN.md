# Causal Worlds Engine — public technical dossier

**Public documentation of a proprietary interactive-world project (v1.1 · 24 November 2026).**

A solo project developed since August 2024, from theoretical grammar to an experimental runtime, using vibe coding on a computer with 8 GB of RAM. The engine and implementation recipes remain private. This repository contains public documentation, high-level results, original diagrams, and observed limitations only.

**Author and project creator: Gaaboy.**

> **In 30 seconds** — The project combines a states–relations–dynamics framework, an experimental multi-domain causal runtime, traceability tools, and interfaces for creating and observing worlds. The complete technical dossier is now available in English in the [English publication package](english/README.md), with Markdown and HTML editions, the short edition, executive summary, diagrams, rights notice, and publication metadata. No engine source code, implementation recipes, internal configuration, or raw data is distributed.

## What the project contributes

The project focuses on an experimental loop: connect specialized mechanisms inside a shared world, follow recorded causes across their changes, then resume and compare branches to examine whether removing a mechanism changes later outcomes. This provides a concrete way to explore chains such as memory → decision → movement → resource, beyond simply placing modules side by side.

The runtime organizes components through access and timing contracts. A static inventory covers 44 phases and 71 components: 49 are classified as reference-step updates, 17 as elapsed-time updates, and 5 as mixed. The dossier describes the current scope and limitations without claiming automatic integration of arbitrary external models or general validation of the framework.

## Observed results

The public dossier covers internal campaigns across multiple domains, including physics, hydrology, locomotion, optics, coordination, causal memory-to-action loops, and branch comparisons. Results are reported by scenario and scope; overlapping campaigns are not added into one global success total. A 47.99-hour endurance record approached but did not formally reach 48 hours, and its final nine minutes recorded no advancing tick. These are internal observations, not an independent audit.
